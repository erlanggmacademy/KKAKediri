Folder ini digunakan untuk menyimpan aset gambar publik statis yang dapat langsung diakses via URL, contoh:
- Logo KKA / Jawa Pos Radar Kediri -> `/images/logo-kka.png`
- Logo Partner (Neutron, Cabdindik, Kemenag) -> `/images/partners/`
- Lambang/Logo 7 Wilayah -> `/images/wilayah/`
- Gambar Galeri / Dokumentasi -> `/images/galeri/`
- Open Graph Banner -> `/images/og-kka-2026.jpg`

Cara memanggil di file Astro / HTML:
<img src="/images/nama-file.jpg" alt="..." />
